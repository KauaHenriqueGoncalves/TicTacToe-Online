    &nbsp;TicTacToe
</h1>

Real-time multiplayer Tic-Tac-Toe game, developed as a capstone project. It features authentication, room management, and real-time communication between players.

## Repository Structure

- **`apresentation/`**: game images and demonstrations
- **`docs/`**: general project documentation (architecture, API, data modeling, etc.)
- **`source-code/`**: project source code (contains its own `README.md`)
